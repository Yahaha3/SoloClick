# SoloKeyClicker - Windows Keyboard Auto Clicker

## 简介
SoloKeyClicker 是一款专为 Windows 设计的高性能键盘连点器。它支持多任务并行、独立按键配置、多种触发模式以及配置导入导出。核心采用底层 Windows Hook 技术，完美解决“按键自触发”导致的死循环问题，支持在游戏中实现“按住连点”或“一键开关”。

## 核心特性
- **多任务并行**：可添加多个按键任务（如：按A连点A，同时按B连点B）。
- **独立配置**：每个任务可独立设置连点频率（毫秒）和触发模式。
- **触发模式**：
  - **Toggle (开关模式)**：按一下开始，再按一下停止。
  - **Hold (按压模式)**：按住持续连点，松开立即停止。
- **独立/互斥模式 (Independent Mode)**：开启后，启动任意一个任务会自动停止其他所有正在运行的任务。
- **防死循环**：智能识别物理按键与模拟按键，支持“按A连点A”而不卡死。
- **配置管理**：支持 JSON 格式的配置导入与导出。

## 安装与运行

1. **环境要求**：
   - Python 3.x
   - Windows 操作系统

2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
   *(依赖 `keyboard` 库用于设置界面的按键捕获)*

3. **运行**：
   ```bash
   python gui.py
   ```
   **⚠️ 重要：请务必以管理员身份运行终端或 IDE**，否则在部分游戏或高权限窗口中无法模拟按键。

## 使用指南

### 1. 添加任务
- 点击 **Add Task**。
- 点击 **Set Key**，然后按下你想要连点的键（支持键盘按键或鼠标键）。
- 设置 **Interval**（连点间隔，单位毫秒）。
- 选择 **Trigger Mode**（Toggle 或 Hold）。
- 点击 **Save**。

### 2. 运行任务
- 在主界面查看任务列表。
- 直接按下你设置的 **Target Key** 即可触发连点。
- **Status** 列会实时显示运行状态。

### 3. 独立模式 (Mutex)
- 勾选工具栏的 **Independent Mode (Mutex)**。
- 此时，如果你启动任务 A，正在运行的任务 B 会自动停止。

### 4. 导出/导入配置
- 使用 **Export Config** 保存当前任务列表。
- 使用 **Import Config** 加载之前的配置。

## 注意事项
- **管理员权限**：如果发现连点在游戏中不生效，请检查是否以管理员权限运行。
- **杀毒软件**：由于使用了底层键盘钩子（Hook）和模拟点击技术，部分杀毒软件可能会误报，请添加信任。

## 日志与排查
- 如果遇到问题，请检查控制台输出（如有）。
- 确保没有其他连点器或脚本工具占用了相同的按键 Hook。
